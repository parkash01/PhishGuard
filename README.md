# 🛡️ PhishGuard

PhishGuard is an advanced Python-based phishing URL security analyzer.

## ✨ Features

- 🔍 Phishing URL analysis
- 🛡️ Risk score from 0–100
- 🚨 LOW / MEDIUM / HIGH / CRITICAL risk levels
- 🌐 HTTPS verification
- 🌍 DNS resolution
- 🔢 IP-address detection
- 🔐 Punycode / IDN detection
- 🔗 Suspicious URL structure detection
- 🏷️ Suspicious TLD detection
- 🎯 Suspicious keyword detection
- 🏢 Brand impersonation detection
- ↪️ Redirect detection
- 🔑 Login/password form detection
- 📊 Scan statistics
- 📜 Scan history
- 🔎 History search
- 📄 TXT and JSON reports
- 🖥️ Tkinter graphical interface
- ⚡ Background URL scanning

## 🛠️ Technologies

- Python
- Tkinter
- DNS / Socket
- HTTP/HTTPS
- SSL
- URL parsing
- CSV / JSON

python phishguard.py
